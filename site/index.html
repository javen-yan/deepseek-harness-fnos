WHY FNOS

不止能打开，更要能扩展

很多 NAS 封装只解决“把主体页面跑起来”。这个版本把重点放在完整 DSH 体验：插件市场、插件安装、native build、工作区权限和安全访问入口一起闭环。

完整运行时

FULL RUNTIME

内置 DSH Web、CLI、插件市场、pnpm、node-gyp 和 native 依赖入口，减少只封主体导致插件不可用的问题。

插件生态

PLUGIN READY

默认使用国内 npm 镜像和 GitHub 下载加速；插件构建走应用私有 pnpm，支持需要 native addon 的插件安装场景。

安全可控

PRIVATE & SAFE

DSH 主服务只监听本机地址，外部通过认证入口访问；工作区和扩展目录遵循 fnOS 授权边界。

ARCHITECTURE

完整 DSH 的运行流转

访问层、DSH 主服务、扩展生态和授权目录分层运行。外部只进入认证入口，扩展能力留在应用私有边界内，DSH 本体保持本机监听。

开始使用

三步，启用完整 DSH

先准备插件构建环境，再上传 FPK。后续插件下载默认走国内 npm 镜像和 GitHub 下载加速；加速项填写 URL 前缀即可，留空使用默认值。适配 fnOS 1.2 及以上版本。

CONFIG

运行配置怎么填

首次安装只需要设置管理密码。网络相关配置已经给了适合国内环境的默认值，普通用户按下面推荐填写即可。

管理密码

至少 8 位，自行设置

用于登录 DeepSeek Harness 访问入口。不要使用 NAS 登录密码，建议单独设置一个强密码。

插件 npm 源

https://registry.npmmirror.com

用于插件市场和第三方插件安装。留空也会使用这个默认源；海外网络可以改为 npm 官方源。

GitHub 加速

https://gh-proxy.com/

这是 URL 前缀，会把 GitHub 下载地址拼到后面。留空使用默认加速源；填 disabled 表示直连 GitHub。
